# Budget Planner UI

A simple **UI-only budget planner web app** built with **React, Tailwind CSS, and shadcn/ui components**.
This project is a **single-page design** where sections change dynamically using JavaScript. It demonstrates how a modern UI for a budget planner could look and feel.

---

## 🚀 Features

* Responsive **single-page UI**
* Built with **React + Tailwind CSS**
* Uses **shadcn/ui components** for modern design
* Interactive components like forms, charts, and transaction lists
* **No database / backend** — this is a **frontend-only demo**

---
## 🛠️ Installation & Setup

### 1. Clone the repository

```bash
git clone repo-budgetplan.git
cd nawinasokan-budgetplan/frontend
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm start
```

The app will run at **[http://localhost:3000](http://localhost:3000)**.
